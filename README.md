# PomoBox · 番茄专注钟

> 🍅 番茄工作法计时器：任务清单、每日专注统计、完成提示音与系统通知 —— 纯前端运行，**数据只存在本机浏览器**。

**在线使用 → <https://pomo.adcakeyuan.top>**

## 功能

- **番茄计时**：专注 / 短休息 / 长休息三阶段自动流转，默认 25-5-15、每 4 轮进入长休息，时长与轮数均可自定义
- **任务清单**：添加任务并「选中」一个作为当前任务，每完成一个番茄自动记 🍅×1，支持勾选完成与清除
- **专注统计**：今日番茄数、专注分钟、累计总数，附最近 7 天柱状图
- **完成提醒**：WebAudio 合成提示音（无音频文件）+ 可选系统通知 + 标签页标题与图标实时显示剩余分钟
- **键盘操作**：`空格` 开始 / 暂停，`R` 重置
- **基于时间戳计时**：切走标签页、休眠唤醒后倒计时依然准确

## 特点

- **零依赖**：原生 HTML / CSS / JavaScript，无框架无构建，离线可用
- **本地存储**：任务与统计数据保存在 localStorage，不上传任何数据
- **深浅色**：跟随系统主题，可手动切换

## 本地运行

无需构建，直接打开 `index.html` 即可。

## 部署

静态站点，推送 GitHub 后由 **GitHub Pages** 托管，自定义域 `pomo.adcakeyuan.top`（CNAME 文件 + Cloudflare DNS）。
